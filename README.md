# TurboWarp-Turbo-Cloud

⚠️注意！
・本カスタム拡張機能で読み書きされるクラウド変数は先頭に「tc_」が付きます。
(例：「score」をカスタム拡張機能を読み書きする場合、「☁tc_score」というクラウド変数に対して読み書きします。)
・クラウド変数を作成/削除するカスタム拡張機能ブロックはエディター時のみ有効です。

🧰機能
・LZSS圧縮
・バッファリング
・指定のクラウド変数の読み書き
・今すぐクラウド変数を送信(バッファリング無視)
・文字列のエンコード(エンコードされた文字列は自動で圧縮されます)



現在の公式最新バージョンは*v0.6.0*です。
